CINEMA — адаптивный макет онлайн-кинотеатра

Файлы:
- index.html — главная страница
- catalog.html — каталог с фильтрами, сортировкой и поиском
- film.html — карточка фильма
- css/style.css — общие стили и адаптив для десктопа, планшета и телефона
- js/main.js — меню, поиск, фильтры, сортировка, список просмотра и интерактивные кнопки

Как запустить:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для полноценной разработки рекомендуется открыть папку в VS Code и запустить через Live Server.

Все постеры и кадры сейчас представлены CSS-заглушками. Их можно заменить изображениями позднее.


Изображения:
Папка assets содержит локальные кинематографические изображения, подключённые к макету через CSS. Изображения стилизованные и сгенерированные, не являются официальными постерами/кадрами фильмов. Для Интерстеллара использована тематическая иллюстрация космонавта и планеты.
